## DosMemo 1.1

### 修正
- **起動時クラッシュを修正**: 1.0 はビルドしたマシン以外で起動直後に終了していました（翻訳リソースの読み込み先がビルド環境の絶対パスになっていたため）。リソースをアプリ本体の `Contents/Resources` から読むよう修正しました。
- メニュー（ファイル・表示など）がシステム標準の項目も含めて日本語表示されるようになりました。
- 指定した文字コード（Shift_JIS など）で表せない文字がある場合、文字を黙って置き換えず、エラーで知らせるようにしました。
- UTF-16（BOM 付き）ファイルを開いて保存すると BOM が二重になる問題を修正しました。

### 新機能
- **Dock メニュー**: Dock アイコンの右クリックから「新規作成」「開く…」。
- **対応形式の拡張**: Markdown / JSON / YAML / XML / プロパティリスト（plist）/ HTML / CSS / JavaScript / シェル / Python / CSV / TSV / TOML / INI / conf / ログ / ソースコードを Finder の「このアプリケーションで開く」から開き、同じ形式で上書き保存できます。「名前を付けて保存」ではファイル形式を選べます。
- **バイナリ plist**: XML として表示・編集し、保存時はバイナリ形式に戻します（構文エラーがあれば保存前に知らせます）。
- 大きなファイルでのカーソル位置・行数計算を高速化しました。ファイルを開いたときのカーソルは先頭に置きます。
